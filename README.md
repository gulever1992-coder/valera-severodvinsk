# ВАЛЕРА: Северодвинск 2003

Открытый мир в духе GTA (вид от третьего лица, интерфейс как в GTA 5) про парня Валеру из Северодвинска начала 2000-х.
Работает прямо в браузере, без установки и без сборки — только статические файлы. Три.js лежит в репозитории (`js/vendor`), интернет для игры не нужен.

## Запуск

**Локально** (нужен Node.js):
```bash
node serve.js
```
Откройте http://localhost:8080. Подойдёт и любой другой статический сервер (`npx serve`, `python -m http.server`). Прямой двойной клик по `index.html` не сработает — браузеры блокируют ES-модули с `file://`.

**По ссылке с GitHub** (GitHub Pages):
1. Создайте репозиторий и загрузите все файлы из этой папки.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)`.
3. Через минуту игра доступна по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

Слабый компьютер: в меню «Настройки» выберите качество **Низкое** (нет теней, меньше разрешение) и уменьшите плотность толпы.

## Управление

| Клавиша | Действие |
|---|---|
| W A S D / Shift / Пробел / C | ходьба / бег / прыжок / присесть |
| Мышь, ЛКМ, ПКМ | камера, удар или выстрел, прицел |
| Q | встать в укрытие (у стены, забора, дерева) |
| R | перезарядка (в машине — смена радиостанции) |
| 1–8, колесо мыши, Tab | оружие / колесо оружия (замедление времени) |
| F | сесть в машину или на велосипед (угнать) |
| E | магазин, ограбить оглушённого прохожего, выйти из машины |
| Пробел в машине | ручник (заносы), H — клаксон, G — мигалка у милицейской |
| M | большая карта с районами |
| Esc | пауза, настройки, сохранение |

## Что есть в игре

- **Город**: центр Северодвинска по спутниковому снимку — б-р Строителей и Приморский парк у моря, ул. Карла Маркса, Трухинова, Арктическая, Ломоносова, Морской проспект (М-8), пл. Кораблестроителей с кольцом и монументом «Мир и труд», ЦУМ, Nord Arena, «Магнит», «Пятёрочка», «Фармация» и др. Хрущёвки, девятиэтажки, сталинки, гаражи, ели и берёзы. Позиции сняты с картинки приблизительно — подгоняйте в `js/mapdata.js`.
- **Живой город**: машины по дорожному графу (Жигули, Волги, «Москвичи», УАЗ, ГАЗели, БМВ-«бумеры», Мерседесы, такси, автобусы), пешеходы, велосипеды, скорая, милицейские патрули, случайные события (ДТП, драки, ограбления, погоня, свадебный кортеж, разборки банд).
- **Время и погода**: сутки идут ~48 минут; ясно / облачно / дождь / гроза / снег / туман; ночью светятся окна и фонари, иногда — северное сияние.
- **Графика**: скелетные скруглённые персонажи с лицами, машины с отражениями, bloom, киношная цветокоррекция, MSAA (отключается в «Низком» качестве).
- **Транспорт**: угон машин (с водителем или припаркованных) и велосипедов, физика с заносами, повреждения, пожары и взрывы.
- **Оружие**: кулаки, бита, нож, ПМ, обрез, МР-153, «Кедр», АКМ, гранаты, коктейли Молотова. Магазины: ЦУМ («Охотник») и чёрный рынок в гаражах.
- **Милиция**: розыск 1–5★, погоня, задержание («ЗАДЕРЖАН» — штраф и изъятие оружия), ОМОН на высоких уровнях. Стереть розыск можно в «Ремонт 3000».
- **Банды и районы**: Солевые, Панки и эмо, Гопники, Новые русские. 11 районов на миникарте, война за район (убивайте людей владельцев, пока их влияние не упадёт до нуля), дань с районов, защита своего района от нападения, союзники «Пацаны Валеры».
- **Сюжет**: пять миссий с кат-сценами и диалогами (вступительная заставка, встреча с Сеней) и свободная игра после финала.
- **Звук**: полностью синтезируется в браузере — шаги по асфальту / траве / снегу, каждое оружие звучит по-своему, двигатели, клаксон, визг шин, сирены, взрывы, дождь, ветер, чайки, гудки заводов, три радиостанции («Радио Шансон», «Europa Plus 2003», «Панк-FM»).

Сохранение — в браузере (localStorage): пауза → «Сохранить игру» или гараж Валеры.

## Устройство проекта

```

serve.js                   мини-сервер для разработки
js/main.js                 запуск, ввод, игровой цикл, сохранения
js/mapdata.js              карта: дороги, районы, точки интереса, вода, леса (в пикселях спутникового снимка)
js/data.js                 банды, оружие, транспорт, магазины
js/city.js                 генерация города: дороги, граф, дома, деревья, фонари, вывески
js/assets.js               процедурные текстуры (+ подмена картинками из assets/textures)
js/models.js               модели: персонажи, оружие, машины, автобус, велосипед
js/env.js                  небо, время суток, погода
js/player.js               Валера: управление, камера, укрытия, машины
js/vehicles.js, peds.js    физика и ИИ транспорта, пешеходов, банд
js/combat.js, police.js    оружие, взрывы; розыск
js/gangs.js, events.js     районы и войны банд; случайные события
js/story.js                миссии и кат-сцены (данными)
js/ui.js                   HUD, миникарта, карта, магазины, колесо оружия
js/audio.js, fx.js         звук (WebAudio), частицы
```

### Как расширять

- **Новая миссия** — добавьте объект в массив `MISSIONS` в `js/story.js`. Типы целей: `goto`, `buy`, `buyWeapon`, `vehicle`, `capture` (и свои в `Story.update`).
- **Новая заставка** — запись в `CUTSCENES` там же: список кадров `{from, to, look, fov, dur, who, text}`, координаты можно давать функцией (например, «за спиной у игрока»).
- **Расширение города** — новые дороги в `ROADS`, районы в `DISTRICTS`, магазины в `POIS` (`js/mapdata.js`). Здания, деревья, фонари, миникарта и дорожный граф достроятся сами.
- **Новая машина / оружие** — `js/data.js` (`VEHICLES`, `WEAPONS`).
- **Настоящие текстуры** — см. `ASSET_PROMPTS.md` (промпты для ChatGPT) и `assets/textures/manifest.json`.
